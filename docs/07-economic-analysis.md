# 经济分析与后续发展

课程十周不按利润验收，但软件工程要求在设计阶段就问清楚：现在烧得起吗、以后靠什么活、怎样避免“有用户没模式”然后消失。暴风影音是反面教材：用户可以很多，模式单一照样退市。

云价格以腾讯云「云+校园」公开学生档为参照：轻量 2 核 4G、5M 带宽、60G SSD，学生认证后一年约 **156 元**（[活动页](https://cloud.tencent.com/act/campus)，以购买页为准）。2 核 2G 一年公开价大约 75 元档，够演示可再降。

## 1. 现在这个项目的经济身份

| 阶段 | 目标 | 怎样算失败 |
| --- | --- | --- |
| 课程（当前） | 文档齐、能演示、代码量与过程规范达标 | 范围失控、P0 演示中断 |
| 单校试用 | 学生机账单撑得住真实小流量 | 为赚钱过早做支付/弹窗 |
| 若做大 | 服务本身有人愿付，而不是只靠广告 | 广告收入占比畸高、体验崩、模式单一 |

V1.0 不做支付，没有资金托管，合规成本和开发成本都低。这是有意的：先证明成团闭环，再谈收费。

## 2. 十周成本（做得出、负担得起）

人力按 6 人 × 10 周 × 12 小时/周 ≈ **720 小时**。用上海常见实习日薪折到小时，只作对照，不入账：

| 单价 | 720 小时 |
| --- | --- |
| 25 元/小时 | 1.8 万元 |
| 40 元/小时 | 2.9 万元 |
| 80 元/小时 | 5.8 万元 |

现金：

| 项 | 低方案 | 基准 | 说明 |
| --- | --- | --- | --- |
| 云主机 | 0（本机 Docker） | 50–160 元 | 学生轻量；2 核 4G 约 156 元/年 |
| 域名 | 0 | 50–80 元/年 | 正式小程序才需要 |
| ICP 备案 | 0 元，耗时数周 | 不挡开发者工具演示 | |
| HTTPS | 0 | 云厂商免费证书 | |
| 对象存储 | 0 | <20 元 | 封面图 |
| 微信 | 个人主体 0 | 企业主体约 300 元/年，后期再说 | |
| 短信 | 0 | 0–30 元 | 可先微信登录 |
| 合计现金 | 0–50 元 | 约 100–270 元 | |

一台 2 核 4G 跑 Docker Compose 足够课程和几百日活。不要为课设买负载均衡。

内测假如 80 周活、服务器按年 156 元摊到每月约 13 元，每人每月约 **0.16 元**。边际成本接近零，直到单机打满。所以 **课程阶段经济可行**。

真正贵的是 720 小时。这笔账换的是完整工程过程（问题→市场→经济→需求→设计→计划→实现），不是再做一个 CRUD。

## 3. 若继续做大：盈利手段（分期，不在 V1.0 做）

原则：先有履约数据，再收费；收费对象优先 **组织者和学校、商家**，而不是对学生弹窗。互动吧商店里已经公开卖主办方会员和流量卡（年卡几十到几百、主办方套餐数百到数千），活动行卖的是企业活动管理，青藤校园墙官网写了抽成、团购、合伙人广告。说明“办活动的人付钱”这条路真实存在。我们只在产品站稳后按需采用，并且不把鸡蛋放进广告一个篮子。

下面金额是设计阶段的**数量级推演**，用来讨论可行性，不是承诺营收。

### 第一层：单校运营（毕业后 3–12 个月）

学生发晚饭局、自习局 **保持免费**，否则供给会立刻干涸。

| 手段 | 卖什么 | 为什么可能有人付 | 粗算（一所学校，保守） |
| --- | --- | --- | --- |
| 社团/院系曝光 | 审核过的置顶、封面位，按场次 | 招新周抢注意力，现在买的是打印海报 | 10 个社团 × 20 元/场 × 10 场 ≈ 2000 元/学期 |
| 学工/团委工具 | 官方活动报名、到场统计、导出 | 学校本来就要统计参与率 | 走创新项目或服务采购，一校一年数千到一两万都可能，以招标为准 |
| 竞赛/实验室组队 | 名单 + 信用记录年费 | 数模、计算机高峰期缺人 | 数个实验室 × 500–2000 元/年 |

这一层不碰支付托管。社团转账走线下或学校财务，平台只提供曝光和名单。现金成本仍是一台轻量 + 域名，**单校可以覆盖账单**。

### 第二层：多校复制（有 1 个学校跑通之后）

互动吧、活动行证明活动工具可以卖套餐；青藤谷官网写“千校千面”按校配置小程序。我们对应成 **按校 SaaS**：一套代码多租户，向学生会技术部、创业团队或学院收年费 + 部署，附带冷启动剧本和审核规范，而不是只卖一次源码。

推演：10 所学校 × 3000–8000 元/年，是小团队可以活的规模，前提是真有一校留存，而不是同时铺 2800 校。运营培训比源码更难被复制。

### 第三层：本地生活（必须企业主体、支付资质齐）

- **饭搭子团购核销**：周边店出套餐，成团后到店，平台抽低佣金。这是活动已经发生之后的增值，不是首页广告墙。
- **运动场馆分时**：羽毛球等本来就要订场，成团后对接余票。

支付、资金托管、食品资质全部属于这一层，**课程范围明确不做**。

### 还可以往哪发展（产品方向，对应经济）

| 方向 | 做什么 | 经济含义 | 风险 |
| --- | --- | --- | --- |
| 社团工作台 | 批量发布、导出、到场 | B 端小额，最该先做 | 要认证流程 |
| 周期性活动 | 每周三跑团 | 留存，仍免费 | 别做成圈子社交 |
| 多租户 | 一校一配置 | SaaS 年费 | 没跑通一校就复制会空 |
| 课表冲突（授权后） | 避开上课时间 | 提高成团率，间接留存 | 无授权不爬教务 |
| 商家核销 | 到店 | 交易佣金 | 合规成本陡增 |
| 数据报告 | 匿名到场率给学工 | 服务费 | 脱敏，不做监控学生 |

不发展的方向：闪聊、树洞、处 CP、首页弹窗、对学生普通报名收费、捆绑插件。

## 4. 对着暴风影音抄作业：怎样才不会“做着做着没了”

招股书口径（多家财经报道转引）：2011–2013 年暴风影音广告收入占主营 **93%、99.95%、99.82%**（贴片、弹窗、Tips、文字链）。用户最高约 2.8 亿仍挡不住模式单一。2014 年广告仍占约 89%，2016 年约 42%，2017 年约 22%——想转型已经晚了。2020 年因未按期披露年报，深交所终止上市，11 月摘牌。早期捆绑插件还伤过口碑。

映射到本项目：

| 暴风做过的 | 我们若学就会怎样 | 设计上的相反选择 |
| --- | --- | --- |
| 收入几乎全是广告 | 未成团先弹窗，体验死、供给没 | 广告永远不当主收入；V1 收入为 0 |
| 内容靠聚合、版权薄 | 搭子做成信息流搬运 | 自己的活动对象和信用流水是资产 |
| 大客户集中 | 一个赞助商撤了就亏 | 多社团小额，不绑单一商家 |
| 用户很多但留不住价值 | 下载量好看、履约没有 | 考核成团和到场，不考核 DAU 吹牛 |
| 转型太晚 | 课设结束就扔 | 预留社团工作台和多租户，不预留闪聊 |

“不像暴风那样退市”的具体含义：

1. **可以缩小**：就算不做商家、不做多校，单校活动工具 + 一台学生机仍然跑得动。暴风不能缩回“小而盈利”，因为服务器和版权是刚性的。
2. **收入结构上限**：内部约定广告不超过总收入一半，超过就停售广告位，先补 B 端订阅。
3. **资产是履约数据**：信用流水、到场率、哪类活动好成团。这些可以卖给组织者做工具，不能拿去给广告点击优化。
4. **主体可升级**：个人主体够课设；真要商家核销再换企业主体，而不是一上来背 300 元认证和支付资质。

## 5. 发展路线（产品演进，对应经济）

| 阶段 | 产品 | 经济 | 退出/收缩策略 |
| --- | --- | --- | --- |
| V1.0 课设 | 发布—报名—信用—推荐降级 | 成本覆盖，收入 0 | 课程结束代码仍可演示 |
| V1.1 | 一键复制到微信；周期性活动 | 仍免费，换留存 | 砍周期活动不影响闭环 |
| V1.2 | 社团工作台、报名导出、到场统计 | 开始 B 端小额 | 没有社团就停在 V1.1 |
| V2.0 | 多校租户、学工对接 | SaaS 年费 | 只保留付费校 |
| V2.x | 商家核销 | 交易佣金，需合规 | 不合规就关掉这一层 |

技术上推荐从规则打分走到有数据再训练，不在没埋点时上模型。校区枚举以后可以接课表，但以超级课程表为鉴：没有官方数据授权就不要爬教务。

规模变大时成本也会变：审核从同学兼职变成要值班；日活到约 5000 再加机器；对象存储和短信才开始显眼。人少了就裁 P2 和 UserCF，不裁报名闭环。

## 6. 盈亏判断

| 问题 | 判断 |
| --- | --- |
| 十周现金够不够 | 够，通常 <300 元 |
| 现在要不要融资、广告、支付 | 不要 |
| 720 小时值不值 | 换完整工程过程，匹配本课 |
| 以后会不会“暴风式”消失 | 若只靠广告和伤害体验的变现，会；若坚持活动工具 + B 端服务费，单校可以活 |
| 网页和小程序是否都要 | 要。小程序失败用网页答辩，网页是低成本兜底 |
| 值不值得做成公司 | 课设阶段不需要这个结论；先看一校是否有周活和社团愿付 |

敏感度：云价翻倍仍可接受；日活到 5000 再加机器；没有社团付费就保持免费工具，不要为了“看起来像创业项目”去卖弹窗。
