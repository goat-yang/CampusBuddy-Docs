# 市场调研

2026-10-17。

## 1. 需求

### 1.1 上海大学

《2023–2024 学年本科教育教学质量报告》：截至 2024-08-31，全日制在校生 **39972** 人（含学历留学生 2320 人），本科生 **19527** 人。PDF：[oiqa.shu.edu.cn/2023-2024bkzlbg.pdf](https://oiqa.shu.edu.cn/2023-2024bkzlbg.pdf)。学校有宝山、延长、嘉定三个校区。

容量按一所综合大学、三个校区来想。人跨校区要花时间，默认只看本校区，用户自己点了才跨区。

### 1.2 大学生里，多数人找过搭子，而且一场就散

汪桂妃《大学生“搭子”社交的形成原因、内在隐患与引导策略》，《社会科学前沿》2025，DOI: [10.12677/ass.2025.146474](https://doi.org/10.12677/ass.2025.146474)。问卷发给双一流、普通本科和高职高专，发出 500 份，有效 355 份；另外访谈 30 人。

| 结果 | 反映什么 |
| --- | --- |
| 72.3% 有过搭子社交 | 这件事在大学生里已经很常见 |
| 68.7% 认为找搭子是突破自我、找新关系的重要方式 | 找搭子被当成一件要紧的事 |
| 57.4% 认为这样高效、省事 | 用户要的是把一件事办完，不是先经营一段关系 |
| 49.2% 担心习惯之后更难建立亲密关系 | 产品和“交朋友、处对象”要分开 |
| 15.7% 和搭子变成了长期关系 | 大多数人用完这场就散。产品按一场活动来做，不做好友列表 |

### 1.3 吃饭、学习、运动最多；学生有需求，但不愿随便装一个交友 App

李佳奇、肖灿、魏嘉仪、靳晴、吴翌琳、蒋妍《“搭子社交 APP”的需求分析与发展战略研究》，中国人民大学统计学院、应用统计科学研究中心，DOI: [10.61369/ASDS.2025060002](https://doi.org/10.61369/ASDS.2025060002)。对象是北京 18–30 岁，配额抽样，发出 462 份，有效 432 份。

| 结果 | 反映什么 |
| --- | --- |
| 75.23% 有过搭子 | 青年里这是多数人的经历 |
| 在校学生 75.88% 有过搭子，愿意用搭子 App 的只有 66.93% | 需求在，现成 App 接不住。论文写的顾虑是安全和隐私 |
| 女性 79.72% 有过搭子，愿意用这类 App 的 64.06% | 女同学更常找搭子，也更在意安全 |
| 活动里聚餐 42.82%、学习 32.64%、运动 28.47% | 冷启动先做晚饭、自习、运动 |
| 有过聚餐搭子的人里，70.81% 愿意用 App | 吃饭这种高频局，本身就有人愿意用工具 |

访谈里，现有 App 多按帖子、性别和位置来配。受访者要的是对着一场具体活动来配。假帖和广告会把人赶走。所以发布页只收类型、时间、地点、人数，匹配也按这场局，不按交友资料。

### 1.4 找搭子多在同学里，看重兴趣和守约，不看脸

中国青年报社社会调查中心联合问卷网，2023-06-01，1335 人（00 后 27.9%、90 后 49.9%、80 后 22.2%）。

[有没有搭子、什么类型](https://zqb.cyol.com/html/2023-06/01/nw.D110000zgqnb_20230601_2-10.htm)：72.6% 生活里有搭子。类型多选：饭 52.9%、运动 43.4%、旅游 37.7%、学习 34.2%。找的时候看重兴趣 70.1%、道德品质 60.8%、节奏合拍 48.5%，外貌 29.5%。

[该注意什么](https://s.cyol.com/articles/2023-06/01/content_2b590Lf3.html)：主要在好朋友（75.8%）和同学同事（62.9%）里找，社交软件网友 37.2%，网络陌生人 13.1%。70.8% 提醒和陌生人出门要注意安全，67.3% 说先把自己的需求说清楚，54.9% 把守约放进注意事项，50.7% 提醒辨别网上的帖子。

人先在同学和朋友里找。兴趣和靠不靠谱的权重大于长相。需求要写具体，不来要有后果。产品做成本校的一场局，写清时间和地点。

### 1.5 校园里看到的也是吃饭、学习和运动

2025-02-20 至 22 日，广西师范大学团队到玉林师范学院等 8 所学校。大学生云报 2025-02-22：玉林师范学院约 82% 的受访者有搭子经历，访谈里约 57% 用游戏搭子、饭搭子这类具体场景来满足需求。[原文](https://www.dxsyb.com/paper/2025/0222/678553.html)。

2025-05-05，同一团队在广西民族大学发问卷。大学生云报 2025-05-13：约 80% 的受访 00 后大学生喜欢搭子社交，日常就是吃饭、学习、运动、娱乐；大家普遍担心被骗。[原文](https://www.dxsyb.com/paper/2025/0513/680563.html)。

单校也有这件事。担心被骗，所以身份要落在本校，不能谁都能进一场局。

### 1.6 低年级更常找，有一批人想过但没去做

温舒艺等《数字时代的社交新模式：大学生中的“搭子社交”》，《社会科学前沿》2024 年第 13 卷第 12 期，DOI: [10.12677/ass.2024.13121080](https://doi.org/10.12677/ass.2024.13121080)。线上有效 5356 份。年级越低越可能参与，社交需求越高越可能参与。另在广东一所大学访谈 579 人：51.12% 找过，32.30% 想过但没行动，16.58% 没想过；85.32% 认为搭子和朋友不是一回事。

冷启动先照顾新生和一件明确的事。发布、报名要短，那 32.30% 才出得来。搭子不是朋友，活动结束关系就可以停。

## 2. 做到多大规模

| 层次 | 范围 | 数字 | 设计上怎么用 |
| --- | --- | --- | --- |
| 上海大学 | 截至 2024-08-31 | 全日制 39972 人，本科 19527 人 | 单机按这个数量级 |
| 本课十周 | 本班和相邻学院 | 50–200 人试用 | 验收时的用户上限 |

容量按 5000 注册、500 日活、每天 200 条活动来做单机，够演示，也够一小段真实试用。

## 3. 别人用来找搭子时，缺的是什么

一场搭子要同时有四样：人是本校的，还差几个名额，时间和地点就在这个校区，不来会留下记录。

| 现在用的 | 找搭子时缺什么 | 我们做不做得到 | 学什么 |
| --- | --- | --- | --- |
| 微信群 | “有人吗”会被刷掉。别的学院搜不到。谁没来，没有记录 | 做得到。按类型、时间、校区列出还没满的局，爽约记入信用 | 成团后的通知发回原来的群，自己不做聊天 |
| Soul | 配的是想聊天的人，不管这场还差几人。没有校区、满员和爽约。奇遇铃按附近的人，不核学号。连麦、处关系和晚饭局在同一个广场 | 名额、校区、信用做得到。语音派对和奇遇铃不做 | 把事情写具体。用兴趣分开，不先看脸 |
| 狐友，含微信小程序里的校园圈 | 组局和二手、跑腿、树洞、生日匹配挤在一个校园社区里。公开介绍没有人数上限、截止时间、候补，也没有不到场会怎样 | 一场局做成独立的一条，做得到。跑腿、树洞、生日匹配不做 | 按学校进。例子用篮球、电影、复习这种具体的事 |
| 搭搭校园 | 口号是“处 CP，找搭子”。配的是人，不是今晚这场局。年龄 18+ | 只做活动。墙、树洞、闪聊不做 | 进学校之前先确认是这个学校的人 |
| 互动吧、活动行 | 报名、限人数、签到、提醒都有。人是同城陌生人，活动是展会和售票。没有学号和校区，食堂差一个人会沉下去 | 报名页、提醒、签到做得到。售票和分销不做 | 一场活动就是一条记录：时间、名额、名单、签到 |
| 青藤谷 | 搭子是外卖、跑腿、二手旁边的一个标签 | 这十周只做组队。外卖和跑腿不做 | 以后再按学校分开配置 |
| 小红书、抖音 | 帖子可以有很多人看。看了不等于报名，报名不等于人来。没有名额，没有爽约记录 | 用报名状态，做得到。不做动态广场 | 第一句写清时间、地点、还差几人 |

多数人已经在找搭子，而且多在同学里找。缺的是这场局谁来、满没满、是不是本校、不来有没有记录。社交 App、校园社区、城市票务各做了一块，没有一块把这四样放在一起。

## 4. 功能按这些缺口来

| 要办的事 | 现在怎么卡住 | 依据 | 这期怎么做 |
| --- | --- | --- | --- |
| 今晚吃饭或自习 | 在群里喊，一会儿就没了 | 聚餐 42.82%、学习 32.64%；饭 52.9%、学习 34.2% | 按今晚和校区筛 |
| 运动还差一两个人 | 不知道还差几人、谁算来了 | 运动 43.4%；北京这份问卷里运动 28.47% | 名额、名单、候补 |
| 跨学院找人 | 人在别的群里 | 找搭子主要在同学同事里，占 62.9%；网络陌生人 13.1%。上大有三个校区 | 只在本校；默认不跨区 |
| 怕放鸽子 | 不来也没有后果 | 看重道德品质的 60.8%；把守约放进注意事项的 54.9% | 信用流水。分太低不能发、不能报 |
| 不想装成交友软件 | 怕不安全，也怕隐私 | 在校学生 75.88% 有搭子，愿意用搭子 App 的 66.93%。70.8% 提醒出行安全，50.7% 提醒辨帖 | 对象是一场活动。可以举报、拉黑。不收学校统一认证密码 |
| 想找，但没发出去 | 步骤多，或者配的不是这场活动 | 32.30% 想过但没行动。访谈要求按一场活动来配，躲开假帖和广告 | 发布不超过 5 步，报名不超过 3 步 |
| 社团要到场名单 | 表格是散的 | 互动吧、活动行已经在做名单和签到 | 后期再做导出 |

冷启动用同学院里还开着的局，加上注册时选的标签。先不做协同过滤。

## 5. 先做这些

1. 一所学校、三个校区。先有一场活动，再谈人与人的关系。
2. 演示先跑晚饭、自习、跑步。调查里饭、学习、运动最高。
3. 先有人真的在报名的活动，再调推荐。
4. 小程序按工具和生活服务来做，不按交友来做。
5. 成团之后，把集合信息复制回原来的微信群。
