# 市场调研

日期：2026-10-15。立项阶段桌面研究。下面只写能打开出处核对的事实，以及这些事实**直接证明什么**。本校问卷第 2 周补一小样本，不挡设计。商店文案、官网自称的用户量一律标明“自称”，不当成独立审计数字。

## 1. 需求侧：公开数据分别证明什么

### 1.1 高校是高密度、可按学校切开的市场

教育部《2024 年全国教育事业发展统计公报》：全国普通、职业本专科在校生 **3891.26 万人**；普通本科学校校均规模 **17428** 人。出处：[教育部门户](https://hudong.moe.gov.cn/jyb_sjzl/sjzl_fztjgb/202506/t20250611_1193760.html)。

**这证明：** 赛道用户总量够大，而且天然按学校切块。适合先做单校，不适合一上来做全国社交。数字本身不证明本校今晚有多少人会来用我们。

### 1.2 目标学校人就在身边，且分校区

上海大学 2023–2024 学年本科教学质量报告：截至 2024-08-31 全日制在校生 **40006** 人（含学历留学生 2320 人），其中本科生 **19527** 人。学校有宝山、延长、嘉定三校区。

**这证明：** 容量按“一所综合大学、三校区”想即可。跨校区通勤真实存在，所以默认不互推、用户显式允许才跨区，比“全上海随便约”更贴近使用。

### 1.3 “搭子”已经是青年听得懂的品类，场景也排得出优先级

中国青年报社社会调查中心联合问卷网，对 **1335** 名受访者（00 后 27.9%、90 后 49.9%、80 后 22.2%）的调查，见《中国青年报》2023-06-01：[原文](https://zqb.cyol.com/html/2023-06/01/nw.D110000zgqnb_20230601_2-10.htm)。《人民日报》评论 2024-05 转引过同一组数字。

调查结果：

| 数字 | 含义 |
| --- | --- |
| 72.6% | 生活里有搭子 |
| 20.0% | 还没有，有需要会找 |
| 7.4% | 没有也不会去找 |
| 68.9% | 认为找搭子是踏出舒适圈的尝试 |
| 53.7% | 认为这是一种高效交往/学习生活方式 |
| 49.3% | 担心会削弱深度人际关系 |
| 45.8% | 认为也可能转化为亲密关系 |

搭子类型（可多选）：饭 **52.9%**、运动 **43.4%**、旅游 **37.7%**、学习 **34.2%**、游戏 **31.1%**、购物凑单 **24.8%**、遛娃 **22.4%**、观影追剧 **19.9%**、露营野餐 **17.1%**、上厕所/打水等校园生活 **8.6%**。

找搭子时看重：兴趣 **70.1%**、道德品质 **60.8%**、节奏合拍 **48.5%**、消费观念 **46.5%**、性格 **43.7%**、时间是否充裕 **34.2%**、外貌 **29.5%**。受访研究生提到位置距离和时间成本。

**这证明：**

- 品类不用再教育，“饭 / 运动 / 学习”就是冷启动剧本。
- 用户要的是**一起做事**，兴趣和履约（品质、节奏、时间、距离）比颜值权重大；外貌不是主因，所以产品叙事不要做成处 CP。
- 样本是全国青年网调，不是上大本校普查。它证明现象存在，不证明本班转化率。本校转化靠第 2 周小样本和第 6 周内测。

### 1.4 大学生群体里，低年级和社交需求高的人更可能找搭子

温舒艺等《数字时代的社交新模式：大学生中的“搭子社交”》，《社会科学前沿》2024 年第 13 卷第 12 期 83–94 页，DOI: [10.12677/ass.2024.13121080](https://doi.org/10.12677/ass.2024.13121080)。线上分层问卷 **5371** 人、有效 **5356** 份；另在广东某大学访谈 **579** 人。文中引用：截至 2024-02-01，抖音相关话题播放约 **73.2 亿**、小红书浏览约 **4.4 亿**、微博讨论约 2.8 万、阅读超 1900 万。

问卷侧：年级与是否参与搭子社交显著负相关（年级越低越可能）；社交需求得分与是否参与显著正相关。访谈侧：579 人中 **296（51.12%）** 曾寻求搭子，**187（32.30%）** 想过但没行动，**96（16.58%）** 没想过；**85.32%** 认为搭子和朋友有明显区别。

**这证明：** 冷启动应偏向新生和明确场景，而不是先做复杂交友或 UserCF。也证明“对象化活动、成团即结束”比“处对象”更贴用户对搭子的理解。想过但没行动的约三分之一，说明工具要把发布和报名步骤压短。

### 1.5 不止北上广有这个现象

广西师范大学社交新象思行团 2025-02-20 至 22 日赴玉林师范学院、广西大学等 8 校调研（大学生云报 2025-02-22 实践报道）。在**玉林师范学院**现场观察：约 **82%** 受访者有搭子经历；访谈约 57% 通过游戏搭子、饭搭子等场景化社交满足需求。

**这证明：** 二线高校同样有这个行为。82% 只描述该校当场样本，不外推全国比例。

综合：人在、词在、场景在。本课要把已经发生在微信群里的行为收成可检索、有名额、能追责的活动对象，而不是发明一种新社交。

## 3. 竞品：真实产品、逐项对照

真正天天在用的替代方案是 **微信群**。下面只放能打开商店、官网或官方文档核对的产品。对比维度统一为：入口、核心功能、组队怎么发生、有没有名额/履约、变现、和我们差在哪。老师追问时按链接和字段答，不编用户量。

毕业设计源码、DCloud 插件、二手“组局小程序模板”不当作市场竞品。

### 3.1 微信群 + 微信接龙 / 腾讯文档接龙（现状）

几乎每个班级、社团都有群。优点：零安装、熟人已在、通知可达。缺点：广播会被刷掉；没有活动对象、状态机、跨学院检索；爽约零记录。

微信后来提供群接龙，腾讯文档也有接龙/收集表。它们能收名单、限人数，但仍是**填表工具**：没有本校活动广场、没有推荐、没有审核与信用流水、没有“候补—成团—签到”闭环。

**和我们：** 成团后把集合信息复制回已有群，不自建 IM。接龙的名单导出思路留给社团端（P2）。

## 5. 进入策略

1. 单校、三校区枚举、先活动后关系。
2. 演示剧本先跑晚饭、自习、跑步三类（对应调查里最高频的饭、学习、运动）。
3. 先有真实可报的活动，再调推荐权重。
4. 小程序按工具类/生活服务准备材料，不按交友 18+ 去讲。
5. 成团后引导复制到已有微信群，不自建 IM。
