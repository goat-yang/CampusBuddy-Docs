# 市场调研

日期：2026-10-17。立项阶段桌面研究。只写能打开出处核对的事实。商店文案、官网自称的用户量标明“自称”。本校问卷第 2 周再补一小样本，不挡设计。

能对上的 2025 年材料用 2025 年。场景排序没有同等口径的新全国调查，2023 年那次还留着，并写明它证明什么。

## 1. 需求还在：找搭子是多数人的事

### 1.1 高校人很多，而且天然按学校切开

教育部《2025 年全国教育事业发展统计公报》（2026-07-06）：全国普通、职业本专科在校生 **3953.96 万人**；普通本科学校校均规模 **17518** 人。出处：[教育部门户](https://hudong.moe.gov.cn/jyb_sjzl/sjzl_fztjgb/202607/t20260706_1442870.html)。公报脚注写明，校均规模只含普通本科、职业本科和高职（专科）在校生，不含研究生。

赛道按学校切块，适合先做单校。这组人数不证明本校今晚有多少人会打开我们。

### 1.2 目标学校的最新公开人数仍是 2024 年 8 月

上海大学信息公开网和教学评估处列出的本科教学质量报告，最新一册是《2023–2024 学年本科教育教学质量报告》。正文：截至 **2024-08-31**，全日制在校生 **39972** 人（含学历留学生 2320 人），其中本科生 **19527** 人。PDF：[oiqa.shu.edu.cn/2023-2024bkzlbg.pdf](https://oiqa.shu.edu.cn/2023-2024bkzlbg.pdf)。学校有宝山、延长、嘉定三个校区。

没有更新的学年报告可替换这份人数。容量仍按“一所综合大学、三个校区”想。跨校区通勤是真的，所以默认不互推，用户点了才跨区。

### 1.3 2025 年，大学生里有搭子的仍是多数

汪桂妃《大学生“搭子”社交的形成原因、内在隐患与引导策略》，《社会科学前沿》2025，DOI: [10.12677/ass.2025.146474](https://doi.org/10.12677/ass.2025.146474)，PDF：[hanspub.org/ass_2399081.pdf](https://pdf.hanspub.org/ass_2399081.pdf)。问卷发给双一流、普通本科、高职高专，发出 500 份，有效 **355** 份（70.1%）；另访谈 30 人。

| 数字 | 问卷原话在说什么 |
| --- | --- |
| 72.3% | 有过搭子社交经历 |
| 68.7% | 认为找搭子是突破自我、寻找新社交关系的重要方式 |
| 57.4% | 认为这是一种高效便捷的社交方式 |
| 49.2% | 认为习惯搭子之后，可能更难建立亲密关系 |
| 15.7% | 和搭子发展成了长期关系 |

这是大学生样本，355 份，不是全国普查。口径是“有过搭子经历”，和 2023 年中青报那次“青年生活里有搭子”的 72.6% 不是同一道题。

更有用的是后两行：绝大多数搭子关系停在一次活动上。产品就该做成“这场局结束就散”，而不是做成好友列表。论文把爽约写成陌生人组局的隐患，没有给比例，这里不编一个爽约率。

### 1.4 场景还是吃饭、学习、运动；人更愿意在同学里找

2025 年没有找到和中青报同口径的全国多选排序（饭 / 运动 / 学习各自百分之几）。能对上的新材料是另一份问卷，外加 2023 年那次调查里还没被换掉的几列。

李佳奇、肖灿、魏嘉仪、靳晴、吴翌琳、蒋妍《“搭子社交 APP”的需求分析与发展战略研究》，DOI: [10.61369/ASDS.2025060002](https://doi.org/10.61369/ASDS.2025060002)，PDF 可打开：[arttechpress.com 该文](https://api.arttechpress.com/uploads/file/asp/202509031707420d60c8910.pdf)。作者单位写的是中国人民大学统计学院、应用统计科学研究中心。抽样总体是北京 18–30 岁，配额抽样，发出 462 份，有效 **432** 份。不是上大，也不是全国。

| 数字 | 含义 |
| --- | --- |
| 75.23% | 有过搭子（325/432） |
| 75.88% | 在校学生里有过搭子 |
| 66.93% | 在校学生愿意使用搭子社交 App；其余中立或不愿意 |
| 79.72% / 64.06% | 女性有过搭子的比例 / 女性愿意用这类 App 的比例 |
| 42.82% | 搭子活动里聚餐最高（185 人） |
| 32.64% | 学习 |
| 28.47% | 运动 |
| 70.81% | 有过聚餐搭子的人里，愿意用 App 的比例，和别的活动差不多 |

论文写：学生和女性更常找搭子，却更不愿意用现成 App，顾虑是安全和隐私。访谈里，现有 App 多按帖子、性别、位置来配，受访者要的是对着一场具体活动来配；假信息和广告会把人赶走。

中青报社会调查中心联合问卷网，1335 人（00 后 27.9%、90 后 49.9%、80 后 22.2%），2023-06-01，两篇是同一次调查：

- [有没有搭子、什么类型](https://zqb.cyol.com/html/2023-06/01/nw.D110000zgqnb_20230601_2-10.htm)：72.6% 生活里有搭子；类型多选为饭 52.9%、运动 43.4%、学习 34.2%。看重兴趣 70.1%、道德品质 60.8%、外貌只有 29.5%。
- [该注意什么](https://s.cyol.com/articles/2023-06/01/content_2b590Lf3.html)：找搭子主要在好朋友（75.8%）和同学同事（62.9%）里，社交软件网友 37.2%，网络陌生人 13.1%。70.8% 提醒陌生人出行要有安全意识，67.3% 说先把自己的需求说清楚，54.9% 把守约互信放进注意事项，50.7% 提醒甄别网上的帖子。

两套数字放在一起，场景没有翻盘：吃饭仍是第一，学习和运动还在前排。中青报多出来的、2025 年问卷没再问的，是“跟谁找”和“看重什么”：多数人先找同学和朋友，不是先找一个城市陌生人；外貌不是主因。所以本校、一场具体的局，比全国交友广场更贴已经发生的行为。

### 1.5 2025 年的校园现场，也是同一件事

这两条是学生实践报道，不是期刊论文。只说明那次、那所学校，不外推全国。

- 2025-02-20 至 22 日，广西师范大学团队到玉林师范学院等 8 校。大学生云报 2025-02-22：玉林师范学院当场约 **82%** 受访者有搭子经历；访谈约 57% 用游戏搭子、饭搭子这类场景满足需求。[原文](https://www.dxsyb.com/paper/2025/0222/678553.html)。
- 2025-05-05，同一团队在广西民族大学发问卷。大学生云报 2025-05-13：报道写约 **80%** 的 00 后大学生喜欢搭子社交，日常常见吃饭、学习、运动、娱乐；受访同学普遍担心被骗。[原文](https://www.dxsyb.com/paper/2025/0513/680563.html)。

### 1.6 2024 年那份大问卷还留下两件 2025 年没再测的事

温舒艺等《数字时代的社交新模式：大学生中的“搭子社交”》，《社会科学前沿》2024 年第 13 卷第 12 期，DOI: [10.12677/ass.2024.13121080](https://doi.org/10.12677/ass.2024.13121080)。线上有效 **5356** 份，广东某大学访谈 **579** 人。年级越低，越可能参与；社交需求越高，越可能参与。访谈 579 人里 51.12% 找过，**32.30%** 想过但没行动，16.58% 没想过；85.32% 认为搭子和朋友不是一回事。

文中的抖音、小红书话题播放量统计到 2024-02-01，不当成现在的热度，这里不再引用。

32.30% 和 2025 年“学生有搭子、但不愿用现成 App”是同一缺口的两截：事情本身被人需要，工具或步骤把人挡住了。

## 3. 找搭子时，别人缺的是哪一块

找一场搭子，要同时有四件事：人是本校的，这场局还差几个，时间地点就在这个校区，不来会留下记录。下面每个产品只回答这四件事里它缺哪件、我们这期做不做得到、有没有一小块值得学。商店和官网链接放在后面，方便核对它是不是真产品。

| 现在拿来凑合的 | 找搭子时满足不了什么 | 我们这期 | 只学这一点 |
| --- | --- | --- | --- |
| 微信群 | 一句“有人吗”会被刷掉。跨学院搜不到。谁没来，没有记录 | 做得到：按类型、时间和校区列出还没满的局；爽约进信用流水 | 成团后的集合通知丢回原来的群，自己不做聊天 |
| 微信接龙、腾讯文档 | 能限人数、能导出名单。没有本校广场，没有候补，没有信用 | 名额和候补做得到。社团导出名单放后期 | 名单怎么收 |
| Soul | 它把想聊天的人配到一起，不守“这场还差几人”。没有校区、满员和爽约。奇遇铃按附近的人，不核学号。连麦和处关系跟晚饭局挤在一个广场 | 名额、校区、信用做得到。语音派对和奇遇铃不做 | 把事情写具体；用兴趣把人分开，不先看脸 |
| 狐友（含微信小程序里的校园圈） | 组局和二手、跑腿、树洞、生日匹配在同一个校园社区里。公开介绍没有人数上限、截止时间、候补，也没有不到场之后会怎样 | 把一场局做成独立对象，做得到。跑腿、树洞、生日匹配不做 | 按学校进；例子用篮球、电影、复习这种具体的事 |
| 搭搭校园 | 口号是“处 CP，找搭子”。配的是人，不是今晚这场局。年龄 18+，交友和找搭子写在一起 | 只做活动对象。墙、树洞、闪聊不做 | 先说明你是这个学校的人 |
| 互动吧、活动行 | 报名、限人数、签到、提醒都有。用户是同城陌生人，活动是展会和售票。没有学号和校区，食堂差一个人会沉到底下 | 报名页、提醒、签到做得到。售票、分销、企业客户管理不做 | 一场活动就是一个对象：时间、名额、名单、签到 |
| 青藤谷 | 搭子是外卖、跑腿、二手旁边的一个标签，还要另外养供给 | 十周只做组队闭环。生活服务大盘不做 | 按学校分开配置，留到以后 |
| 超级课程表 | 搭子绑在课表和同班同学上。晚饭、跑步、竞赛不在课表里 | 时间和校区由发布的人自己填。不爬教务 | 真要用来判断时间冲突，必须先有官方授权 |
| 小红书、抖音 | 帖子可以被很多人看见。看见不等于报名，报名不等于人来了。没有名额，没有爽约记录 | 用报名状态，做得到。不做动态广场 | 第一句就写时间、地点、还差几人 |

空出来的不是“青年不找搭子”。第 1 节的 2025 年问卷里，有过搭子的仍是多数，而且多数人本来就在同学和朋友里找。空出来的是：这场局谁来、满没满、是不是本校、不来有没有记录。社交 App、校园社区、城市票务、课表各拿走一块，没有一块把这四件事放在一起。报名状态和信用流水就是对着这个缺口。

### 3.1 核对用的产品页

毕业设计源码、插件市场里的组局模板，不算市场上的产品。

**微信群、接龙。** 班级群和社团群已经在用。微信群接龙和腾讯文档收集表能收名单、限人数，仍然是一张表。

**Soul。** 上海任意门科技有限公司，公司 2015 年成立，App 2016 年上线。[关于我们](https://www.soulapp.cn/about)：虚拟形象，不靠现实身份和外貌，按兴趣图谱匹配。[怎么用 Soul 找搭子](https://www.soulapp.cn/en/media/questions/q-009)：在瞬间广场写清意图，例子是“每晚十点找人连麦打游戏”“周末想去看展”；群聊派对里一个房间十几个人，聊十分钟看谁合拍；线下用奇遇铃，时间和地点自己再定。

**狐友。** 搜狐的社交产品，[t.sohu.com](https://t.sohu.com/) 口号是“校园生活，从狐友开始”，圈子按同好或同校。2022 年校园圈合作稿写过跳进微信小程序，功能里有匿名树洞、校园集市、组局，并对圈主写了扶持、分成和广告（[转载页](https://www.10100.com/article/145983666)）。央广网 2025-03-15 把组局写成篮球赛、电影聚会、期末复习，旁边还有学习求助、二手、跑腿、树洞和生日匹配（[原文](https://tech.cnr.cn/techph/20250315/t20250315_527101856.shtml)）。“覆盖全国大部分高校”“发一条就有人报名”是这篇稿子的宣传句。

**搭搭校园。** [App Store](https://apps.apple.com/cn/app/搭搭校园-大学生都在用/id6720758529) ID `6720758529`。开发者北京八分书科技有限公司。分类社交，年龄 **18+**。商店文案自称覆盖 2800+ 所高校，口号“处 cp，找搭子”。功能写了校园墙、树洞、闪聊、跳蚤市场，以及学习、考研、健身等“搭一搭”。评分条数少，不能当口碑。

**互动吧。** [App Store](https://apps.apple.com/cn/app/互动吧-活动发布和售票平台/id797346491) ID `797346491`，北京佐敦网络科技有限公司。商店功能是发布、售票核销、报名表单、签到、渠道统计。品类是亲子、户外、职场、运动等城市活动。注册量和主办方数量是商店自称。

**活动行。** [huodongxing.com](https://www.huodongxing.com/)。一分钟建报名页，H5 / 小程序 / App，免费票和付费票，名单和验票。首页是展会、分享会、路演。公开材料里有认证费和年版企业套餐，具体价格以官网当时的报价页为准。

**青藤谷。** [qingtenggu.com](http://www.qingtenggu.com/)，山东青藤谷网络技术有限公司，鲁ICP备2025146457号-1。官网功能包括外卖、跑腿、表白墙、搭子社交、二手、团购。覆盖高校数和日均订单是官网自称。

**超级课程表。** [App Store](https://apps.apple.com/cn/app/超级课程表-大学生早八上课必备课表极简好用/id573868981) ID `573868981`。更新说明写过支持大量高校导课表，并有“同班同学 / 上课搭子”。Android 包名 `com.xtuone.android.syllabus`。

## 5. 进入时按这个顺序

1. 单校、三个校区，先有一场局，再谈关系。
2. 演示先跑晚饭、自习、跑步。2023 年和 2025 年的排序都把吃饭放在第一，学习和运动没有掉出去。
3. 先有人真实在报的活动，再调推荐权重。
4. 小程序按工具、生活服务来准备材料，不按 18+ 交友来讲。
5. 成团后把集合信息复制回已有微信群。
