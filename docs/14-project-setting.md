# 项目设定文字稿

供课程系统“项目名称 / 项目描述 / 项目状态”复制。以下为计划，不表示系统已实现。

## 项目名称

软件工程校园搭子平台项目

## 项目描述

学生在拼饭、自习、运动、竞赛等场景需要临时结伴，但班级群广播难以检索、跨学院触达弱、爽约没有记录。本项目拟做本校轻量组队系统：微信小程序与 Web 发布带类型、时间、校区和人数上限的活动；报名在服务端用原子计数与唯一索引防止超员；信用分只通过流水加减，连续爽约将被限制发布或报名；首页推荐采用可解释的多因子加权并可降级为热度榜。管理后台承担审核、举报和数据看板。不做支付、即时通讯和跨校开放。六人计划十周交付可演示闭环。
