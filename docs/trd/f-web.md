| 项 | 内容 |
| --- | --- |

用户端：学号/工号登录（首次学校邮箱验证码，之后本平台密码）、列表搜索、详情、报名、个人中心、消息。登录页不得要求学校统一认证密码。后台：审核工作台、用户管理、举报、推荐参数表单（调 C 的 config 接口，提交前校验权重和为 1）、数据看板、操作日志。

部署：Compose 启动 mysql、redis、api、nginx。网页用浏览器打开 IP 或域名即可。与小程序共用该 API。备案属于加分项，不阻塞第 9 周联调。见 [部署说明](../13-deployment.md)。

验收：干净环境按手册冒烟；看板数字与 `/admin/stats` 一致；演示含成功报名、满员、敏感词拦截。
