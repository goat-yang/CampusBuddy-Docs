# 子 TRD A｜用户、鉴权、RBAC

| 项 | 内容 |
| --- | --- |
| 责任 | A（项目经理 / 后端） |
| 预估 | 1500 行 + 需求文档收口 |
| 技术 | JDK 17、Spring Boot 3、JWT、BCrypt、注解拦截 |
| 所有权 | 登录注册、令牌、RBAC、个人主页、兴趣标签 |
| 接口 | 契约 1–7 |

微信 `code` 与账号密码两种 `mode` 都签发同一套 JWT，保证小程序扫码预览和网页登录是同一用户表。不实现报名锁和推荐。权限只认服务端角色。

验收：游客报名 401；越权 403；口令 BCrypt；过期 token 可刷新。
