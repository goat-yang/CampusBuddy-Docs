# 子 TRD A｜用户、鉴权、RBAC

| 项 | 内容 |
| --- | --- |
| 责任 | A（项目经理 / 后端） |
| 预估 | 1500 行 + 需求文档收口 |
| 技术 | JDK 17、Spring Boot 3、JWT、BCrypt、邮箱验证码、注解拦截 |
| 所有权 | 登录注册、**上大邮箱验证码**、学号/工号绑定、本平台密码、令牌、RBAC、个人主页、兴趣标签 |
| 接口 | 契约 1–7 及 `POST /auth/otp/send` |

V1.0 主路径：学号/工号 + 本平台密码；首次用上大邮箱验证码证明本校身份。微信 `code` 只作小程序预览兜底，绑定 `campusId` 后才能报名发布。三种入口发同一套 JWT。不实现报名锁和推荐。权限只认服务端角色。

**禁止**在本系统收集或校验学校统一认证密码。SSO 是后接能力，申请步骤见 [校园身份](../16-campus-identity.md)。

验收：游客报名 401；越权 403；口令 BCrypt；过期 token 可刷新；非白名单邮箱域拒绝发码；验证码不明文写日志。
