# 子 TRD E｜微信小程序

| 项 | 内容 |
| --- | --- |
| 责任 | E（小程序前端） |
| 预估 | 2400 行 |
| 技术 | 原生小程序、Vant Weapp、统一 request |
| 所有权 | 学生端全部页面、订阅消息授权、apiBase 分环境 |

页面：首页推荐流、活动列表与筛选、详情、发布表单、报名、我的报名/我的发布、消息、个人中心、登录（学号/工号 + 本平台密码；首次学校邮箱验证码）。微信登录仅作预览，未绑学号不能报名发布。请求带 JWT，401 跳登录，错误用接口 `message`。不在前端判断能否报名。登录文案不得写成“统一认证密码”。

部署：默认在微信开发者工具预览，真机扫码调试，详情勾选不校验合法域名，`apiBase` 指向电脑局域网 IP 或云主机上的同一后端。域名备案完成后，再配置 request 合法域名并提交审核。步骤见 [部署说明](../13-deployment.md)。

验收：发布不超过 5 步、报名不超过 3 步；与网页用同一测试账号能看到同一条活动。
