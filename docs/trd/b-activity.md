# 子 TRD B｜活动发布、检索、报名状态机

负责人：hl-matrix

| 项 | 内容 |
| --- | --- |
| 责任 | B（后端） |
| 配套 | 数据库设计文档 |
| 技术 | 事务、Redis DECR、唯一索引、定时任务 |
| 所有权 | 活动 CRUD/检索、报名、候补递补、签到、成团扫描、收藏 |
| 接口 | 契约 8–21、34–35 |

名额与时间冲突只在 B 实现。C 过滤已报名须查 B 的数据。结束时逐人标记到场或未到场，再交给 D。未标记的报名保持待结算，D 不加分也不扣分。

不变量：有效报名人数不超过 maxNum；同一用户同一活动一条未取消记录；开始时间差小于 60 分钟不可同时报名；满员报名进入候补，取消后按序递补。审核通过后状态为报名中，没有单独的已发布。未打开「需要确认」的报名直接已通过并占名额；打开后为待确认，不占正式名额。`SIGNUP` 和仍有名额的 `GROUPED` 都可以报名。

验收：并发报名上限 1 不超员；幂等键不插第二行；列表不含草稿/驳回/已下架。
