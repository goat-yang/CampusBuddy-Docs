# 子 TRD B｜活动发布、检索、报名状态机

| 项 | 内容 |
| --- | --- |
| 责任 | B（后端） |
| 预估 | 1700 行 + 数据库设计文档 |
| 技术 | 事务、Redis DECR、唯一索引、定时任务 |
| 所有权 | 活动 CRUD/检索、报名、候补递补、签到、成团扫描、收藏 |
| 接口 | 契约 8–21、34–35 |

名额与时间冲突只在 B 实现。C 过滤已报名须查 B 的数据。finish 时把到场名单交给 D 记信用。

不变量：有效报名人数不超过 maxNum；同一用户同一活动一条未取消记录；开始时间差小于 60 分钟不可同时报名；满员报名进入候补，取消后按序递补。

验收：并发报名上限 1 不超员；幂等键不插第二行；列表不含草稿/驳回/已下架。
